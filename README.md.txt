
# Catálogo provisional — Forrajería R&A

## Objetivo

Mostrar los alimentos para perros y gatos del negocio
mediante un catálogo web estático.

El catálogo permitirá buscar productos, aplicar filtros
y consultar por WhatsApp.

## Fuente de imágenes

Las imágenes originales se encuentran en OCI Object Storage.

No modificar las rutas ni los archivos originales utilizados
por el proyecto principal de Productos Regionales R&A.

## Reglas para agregar productos

1. Cada producto debe tener un identificador único.
2. Utilizar únicamente nombres y características verificadas.
3. Registrar la categoría como "perros" o "gatos".
4. Agrupar las presentaciones del mismo alimento.
5. Utilizar las URL públicas HTTPS de las imágenes de OCI.
6. No incluir precios, credenciales ni información administrativa.
7. Verificar que cada imagen corresponda al producto registrado.
